\section*{問題設定においていくつか変更を行なった箇所と、確認するポイント}
\label{sec:orgd8a3721}

\subsection*{現在の問題設定}
\label{sec:org6affa3b}
ノードs〜ノードd 間のリンク集合 Ｌ だけでなく、

ノードS〜ノードD\_n間のリンク集合 L\_n (\(1 \le n \le N\), N はノードSの隣接ノード数)がそれぞれ入力される。

ノードS〜ノードD\_n間の重要度 I\_n (0〜1 の値) が入力として与えられる。

総バウンスコスト C が入力として与えられる。

この時、ノードS〜ノードD\_n のノードペアの中で、

K 個のノードペア (S, D\_s\_1), (S, D\_s\_2), \ldots{} (S, D\_s\_K) における

忠実度が最大のリンクをそれぞれ発見する。

ただし、発見するリンクのノードペア数 K は、

重要度と忠実度の積の総和、つまり

I = \(\sum\)\_\{k = 1\}\^{}K I\_s\_k * F\_s\_k

が最大となるように定める。

ここで F\_n は (S, D\_n) 間において忠実度の最大のリンクの忠実度である。



\subsection*{Kは静的に決まるものかどうか？(確認点、変更点)}
\label{sec:org48c5afd}
K の扱い: 「K個選ぶ」のか、それとも「スコアの総和を最大化するために K
も最適化対象とする（ナップサック問題的アプローチ）」のか、厳密な再確認。


重要度 I も忠実度 F も正の値（0<I,F≤1）であるため、積 I×F は常にプラス
になる。 したがって、「総和を最大にする K」を求めると、常に K=N（全て
の宛先を選択する）ことが答えになってしまう。


静的にきまる → K が入力として与えられる。K = 3なら上位3個の宛先を選択
する。


\subsection*{予算をCで固定しない(変更点)}
\label{sec:orge992e64}
LINKSELFIEの核心的な貢献は「非線形回帰特有の狭い信頼区間（Lemma 1）」
を利用して探索効率を上げることにあるため、そのメリットを殺してしまう固
定予算（Fixed Budget）設定よりも、固定信頼度（Fixed Confidence）設定を
採用する方が圧倒的に論文としてのストーリーが強固になる。

本研究では、既存の単一宛先リンク選択問題（LINKSELFIE）を、宛先重要度を
考慮した複数宛先選択問題へと拡張する。この際、問題設定として「固定予算
（Fixed Budget）」ではなく**「固定信頼度（Fixed Confidence）」**を採用
する。その理由は以下の通りである。


\begin{itemize}
\item LINKSELFIEの本質（Lemma 1的除去）: LINKSELFIEの優位性は、非線形回帰
モデルから導出された「Hoeffding不等式よりも狭い信頼区間（Lemma 1）」
にある。この手法は、統計的に有意な差（信頼区間の分離）が確認された時
点で除去を行う「適応的な停止規則」を前提としている。

\item 固定予算の弊害（SR的除去）: 固定予算設定で用いられる逐次除去
（Successive Rejects）は、予算消化のために「現時点で最下位の候補」を
強制的に除去する。これ導入すると、統計的有意性を無視することになり、
LINKSELFIE最大の武器であるLemma 1の信頼区間を利用する理論的根拠が失
われる。
\end{itemize}


\section*{new問題設定(箇条書き形式)}
\label{sec:org6b6ef22}

\section{Problem Definition}

本問題を、ネットワークベンチマーキング（NB）の枠組みに基づき、以下の入力、出力、および最適化目標を持つ形式として定義する。

\begin{itemize}
    \item \textbf{入力 (Input):}
    \begin{itemize}
        \item ネットワーク構成: ソースノード $S$ および $N$ 個の宛先ノード集合 $\mathcal{D} = \{D_1, \dots, D_N\}$
        \item 候補リンク集合: 各ペア $(S, D_n)$ 間の物理リンク集合 $\mathcal{L}_n = \{l_{n,1}, \dots, l_{n, M_n}\}$
        \item \textbf{バウンス番号セット (Bounce Number Set):} NBで使用するバウンス回数の集合 $\mathcal{M} = \{m_1, m_2, \dots, m_{|\mathcal{M}|}\} \subset \mathbb{N}^{+}$ 
        \item 重要度: 各宛先 $D_n$ の通信需要 $I_n \in (0, 1]$ (既知の定数)
        \item 通信制約: 選択する宛先数の上限 $K$ ($1 \le K \le N$)
        \item 信頼度パラメータ: 許容誤り確率 $\delta \in (0, 1)$
    \end{itemize}

    \item \textbf{出力 (Output):}
    \begin{itemize}
        \item 選抜宛先集合 $\mathcal{S}_{\mathrm{out}} \subset \mathcal{D}$ (ただし $|\mathcal{S}_{\mathrm{out}}| = K$)
        \item 選抜リンク集合 $\mathcal{L}_{\mathrm{out}} = \{l_n^* \in \mathcal{L}_n \mid D_n \in \mathcal{S}_{\mathrm{out}}\}$
    \end{itemize}
    
    \item \textbf{仮定 (Assumption):}
    \begin{itemize}
        \item \textbf{実現可能性:} 宛先総数は選択数以上である ($N \ge K$)。
        \item \textbf{タイブレイク:} 重要度重み付き忠実度和 $J$ を最大化する宛先集合が複数存在する場合、そのうち任意の1つを出力すれば正解とみなす。
    \end{itemize}

    \item \textbf{正解性制約 (Correctness Constraint):}
    アルゴリズムの出力 $(\mathcal{S}_{\mathrm{out}}, \mathcal{L}_{\mathrm{out}})$ が、真の最適解の集合 $\Omega^*$ に含まれる確率を保証すること。
    \begin{equation}
        \mathbb{P}\left( (\mathcal{S}_{\mathrm{out}}, \mathcal{L}_{\mathrm{out}}) \in \Omega^* \right) \ge 1 - \delta
    \end{equation}
    ここで $\Omega^*$ は、目的関数 $J = \sum_{D_n \in \mathcal{S}} I_n \cdot \max_{l \in \mathcal{L}_n} F_{n,l}$ を最大化する全てのペア $(\mathcal{S}, \mathcal{L})$ の集合である。

    \item \textbf{最適化目標 (Optimization Goal):}
    正解性制約を満たすアルゴリズムの中で、停止するまでに消費する**総バウンス数 (Total Bounce Cost)** の期待値を最小化すること。
    すなわち、各リンク $l$ へのベンチマーキング実施回数を $T_l$ としたとき、以下のコスト $C_{\mathrm{total}}$ を最小化する。
    \begin{equation}
        \text{Minimize } \quad \mathbb{E}[C_{\mathrm{total}}] = \mathbb{E}\left[ \sum_{n=1}^{N} \sum_{l \in \mathcal{L}_n} T_l \cdot \left( \sum_{m \in \mathcal{M}} m \right) \right]
    \end{equation}
\end{itemize}

\subsection*{問題設定(論文)}
\label{sec:org21fb8df}
\section{Problem Formulation}

本研究では、量子ネットワークにおけるリソース制約と宛先重要度を考慮したリンク選択問題を扱う。
ソースノード $S$ と、$N$ 個の宛先ノード集合 $\mathcal{D} = \{D_1, \dots, D_N\}$ からなるスター型トポロジーを想定する。
各ノードペア $(S, D_n)$ 間には、物理的経路の違い等に由来する候補リンク集合 $\mathcal{L}_n$ が存在し、各リンク $l \in \mathcal{L}_n$ は未知の忠実度 $F_{n,l}$ を持つと仮定する。これらはネットワークベンチマーキング（NB）によってのみ推定可能である。
また、各宛先 $D_n$ には、通信需要を表す重要度 $I_n \in (0, 1)$ が既知の定数として付与されている。


本問題の目的は、同時にエンタングルメントを確立する宛先ノード数が $K$ ($1 \le K \le N$) を上限とする制約下で、システム全体の「重要度重み付き忠実度和」を最大化する通信構成を決定することである。
各宛先 $D_n$ のスコア $V_n$ を次式で定義する。
\begin{equation}
    V_n = I_n \cdot \max_{l \in \mathcal{L}_n} F_{n,l}
\end{equation}

最適化の目標は、スコアの和を最大化するサイズ $K$ の宛先集合 $\mathcal{S}_{\mathrm{out}}$ および、各宛先の最良リンク $l_n^*$ を特定することである。
すなわち、以下の目的関数 $J$ を最大化する解を求める。
\begin{equation}
    \text{Maximize } \quad J(\mathcal{S}_{\mathrm{out}}) = \sum_{D_n \in \mathcal{S}_{\mathrm{out}}} V_n
\end{equation}

\paragraph{Assumption 1 (Tie-breaking and Feasibility):}
\begin{itemize}
    \item 宛先総数 $N$ は選択数 $K$ 以上であるとする ($N \ge K$)。
    \item スコア $V_n$ にタイ（同値）が存在し、最適解 $\mathcal{S}^*$ が一意に定まらない場合、アルゴリズムは目的関数 $J$ を最大化する任意の集合 $\mathcal{S}^*$ を一つ出力すれば正解とみなす。
\end{itemize}

本問題は、固定信頼度（Fixed Confidence）設定におけるサンプル複雑性最小化問題として定式化される。
\begin{align}
    \textbf{Minimize:} \quad & \mathbb{E}[\text{Total Bounce Cost}] \\
    \textbf{Subject to:} \quad & \mathbb{P}\left( J(\hat{\mathcal{S}}_{\mathrm{out}}) < J(\mathcal{S}^*) \lor \hat{\mathcal{L}}_{\mathrm{out}} \neq \mathcal{L}^*(\hat{\mathcal{S}}_{\mathrm{out}}) \right) \le \delta
\end{align}
ここで $\mathcal{L}^*(\mathcal{S})$ は集合 $\mathcal{S}$ 内の各宛先における真の最良リンク集合を表す。


\subsection*{この問題設定に対応するストーリー案の骨格}
\label{sec:org47f9612}
背景

量子ネットワークでは、ノード間のエンタングルメントリンクの忠実度が通信
品質を決定する重要な指標である。忠実度はネットワーク状態の変動に伴い変
化するため、通信に先立ち高忠実度のリンクを判定する必要がある。この問題
に対し、限られた計測回数（バウンス）のもとで送受信ノード間の最大忠実度
リンクを効率的に特定する手法としてLinkSelFiEが提案されている。

動機

しかしLinkSelFiEは単一の送受信ノードペアのみを対象としている。現実の量
子ネットワークでは、量子スイッチやQKDアクセス網のように一つのノードが
複数の宛先と同時に通信需要を持つ場面が存在する。各宛先への需要の重要度
は一様ではなく、限られたバウンス予算を重要度に応じて複数宛先間で適切に
配分しながらリンクを判定する仕組みが求められる。

目的

本研究ではLinkSelFiEを複数宛先・通信需要を考慮した設定に拡張する。具体
的には、各宛先の重要度と忠実度の積の総和を最大化するように、限られたバ
ウンス予算のもとで検証すべき宛先の選択と各宛先における最大忠実度リンク
の判定を同時に行う手法を提案する。これにより資源制約下で実用的なリンク
選択が可能となる。




\section*{手法(変更した問題設定での手法)}
\label{sec:org6c8609e}
\section{Algorithm: MD-LINKSELFIE}

\subsection{Overview}

提案法 MD-LINKSELFIE は、適応的な二重除去（Dual Elimination）メカニズムを持つフェーズベースの探索アルゴリズムである。本アルゴリズムは、各フェーズで生存している候補リンクに対してネットワークベンチマーキング（NB）を実行し、得られた推定値の信頼区間に基づいて以下の二つの除去判定を行う。

\begin{itemize}
    \item \textbf{内層除去 (Inner Elimination):} 各宛先 $n$ 内部において、その宛先内の最良リンクと比較して統計的に有意に劣るリンクを除去する。
    \item \textbf{外層除去 (Outer Elimination):} 宛先集合全体において、重要度重み付きスコアが上位 $K$ 位以内に入る可能性が統計的に否定された宛先を除去する。
\end{itemize}

これらは統合されたループ内で並行して実行される。内層除去は不必要なリンクへのリソース配分を削減し、外層除去は重要度の低い宛先や品質の低い宛先を早期に切り捨てる役割を果たす。

\subsection{Initialization}

全 $N$ 個の宛先を初期アクティブ宛先集合 $\mathcal{A} \leftarrow \{D_1, \dots, D_N\}$ とする。各宛先 $n \in \mathcal{A}$ について、全リンクを初期アクティブリンク集合 $\mathcal{S}_n \leftarrow \mathcal{L}_n$ とする。
フェーズカウンタを $s \leftarrow 1$、累積反復回数を $T_0 \leftarrow 0$ に初期化する。

\subsection{Execution Loop}

以下の\textbf{停止条件}が満たされるまで、フェーズ $s = 1, 2, \dots$ を繰り返す。

\begin{equation}
    \text{停止条件: } |\mathcal{A}| = K \quad \land \quad \forall n \in \mathcal{A}, |\mathcal{S}_n| = 1
\end{equation}
(すなわち、アクティブな宛先が $K$ 個に絞り込まれ、かつ残った各宛先の候補リンクが1本に特定された時点で停止する。)

各フェーズでは以下の手順を実行する。

\subsubsection{1. Setting Repetition Counts}
フェーズ $s$ における累積反復回数 $T_s$ を、補題 \ref{lem:confidence} (Lemma 1) に基づき次式で設定する。
\begin{equation}
    T_s = C_{\mathrm{NB}} \cdot 2^{2s} \cdot \log\left( \frac{(s+1)(s+2) N L_{\max}}{\delta} \right)
\end{equation}
ここで、$C_{\mathrm{NB}}$ はシステム定数、$L_{\max}$ は宛先あたりの最大リンク数である。本フェーズで追加実行する反復回数を $\Delta T = T_s - T_{s-1}$ とする。

\subsubsection{2. Benchmarking and Estimation}
各アクティブ宛先 $n \in \mathcal{A}$ の各アクティブリンク $l \in \mathcal{S}_n$ に対して、NBサブルーチンを $\Delta T$ 回実行する。
各バウンス数 $m \in \mathcal{M}$ における生存確率の測定値について、過去のデータと統合し、加重平均を用いて累積平均生存確率 $b_{n,l,m}^{(s)}$ を更新する。
\begin{equation}
    b_{n,l,m}^{(s)} = \frac{b_{n,l,m}^{\text{new}} \cdot \Delta T + b_{n,l,m}^{(s-1)} \cdot T_{s-1}}{T_s}
\end{equation}
このデータを指数モデル $b_m = A p^{2m}$ にフィッティングし、現時点での脱分極パラメータ推定値 $\hat{p}_{n,l}^{(s)}$ を得る。

\subsubsection{3. Confidence Radius Calculation}
フェーズ $s$ における信頼半径 $\varepsilon_s$ を計算する。
\begin{equation}
    \varepsilon_s = \sqrt{\frac{C_{\mathrm{NB}}}{T_s} \cdot \log\left( \frac{(s+1)(s+2) N L_{\max}}{\delta} \right)}
\end{equation}
この信頼半径により、確率 $1-\delta$ 以上で $|\hat{p}_{n,l}^{(s)} - p_{n,l}| \le \varepsilon_s$ が保証される。

\subsubsection{4. Inner Elimination (Link Selection)}
各アクティブ宛先 $n \in \mathcal{A}$ について、最良リンク候補を特定し、劣等リンクを除去する。
まず、宛先内の最大推定値 $\hat{p}_{\max,n} = \max_{l \in \mathcal{S}_n} \hat{p}_{n,l}^{(s)}$ を求める。次に、上側信頼限界が暫定最良リンクの下側信頼限界を下回るリンクを除去する。
\begin{equation}
    \mathcal{S}_n \leftarrow \mathcal{S}_n \setminus \left\{ l \in \mathcal{S}_n : \hat{p}_{n,l}^{(s)} + \varepsilon_s < \hat{p}_{\max,n} - \varepsilon_s \right\}
\end{equation}
除去後、宛先 $n$ の代表忠実度 $\hat{F}_n$ および重要度重み付きスコア $\hat{V}_n$ を更新する。
\begin{equation}
    \hat{F}_n = \frac{\hat{p}_{\max,n} + 1}{2}, \quad \hat{V}_n = I_n \cdot \hat{F}_n
\end{equation}

\subsubsection{5. Outer Elimination (Destination Selection)}
現在のアクティブ宛先数が $K$ を超えている場合（$|\mathcal{A}| > K$）に限り、宛先の除去を行う。
各宛先 $n$ のスコア $\hat{V}_n$ に対する信頼区間の幅は $I_n \cdot \varepsilon_s$ である。上側信頼限界 (UCB) と下側信頼限界 (LCB) を次式で計算する。
\begin{equation}
    \mathrm{UCB}_n = I_n \left( \hat{F}_n + \frac{\varepsilon_s}{2} \right), \quad \mathrm{LCB}_n = I_n \left( \hat{F}_n - \frac{\varepsilon_s}{2} \right)
\end{equation}
現在のアクティブ集合 $\mathcal{A}$ の中で、$K$ 番目に大きい下側信頼限界を閾値 $\Theta_K$ とする。
\begin{equation}
    \Theta_K = \text{The } K\text{-th largest value in } \{ \mathrm{LCB}_n \}_{n \in \mathcal{A}}
\end{equation}
UCBがこの閾値を下回る宛先は、Top-Kに入る可能性がないため除去する。
\begin{equation}
    \mathcal{A} \leftarrow \mathcal{A} \setminus \left\{ n \in \mathcal{A} : \mathrm{UCB}_n < \Theta_K \right\}
\end{equation}

\subsubsection{6. Phase Update}
フェーズカウンタを更新し（$s \leftarrow s + 1$）、次のフェーズへ移行する。

\subsection{Output}
停止条件を満たした時点での $\mathcal{A}$ を出力宛先集合 $\mathcal{S}_{\mathrm{out}}$ とし、各宛先 $n \in \mathcal{S}_{\mathrm{out}}$ に残った唯一のリンク $\{l_n\} = \mathcal{S}_n$ を最良リンク $l_n^*$ として出力する。


\subsection*{この手法の解析}
\label{sec:org5860882}

\section{Theoretical Analysis}

本節では、MD-LINKSELFIEの理論的保証を与える。まず、解析に必要なギャップを定義し、その上でサンプル複雑性の上界を示す。

\subsection{Gap Definitions}

\begin{definition}[Inner Gap]
宛先 $n$ 内におけるリンク $l \in \mathcal{L}_n$ の内層ギャップ $\Delta_{n,l}^{\mathrm{in}}$ を以下で定義する。
\begin{equation}
    \Delta_{n,l}^{\mathrm{in}} := \begin{cases}
    F_{n,l_n^*} - F_{n,l_n^{(2)}} & \text{if } l = l_n^* \\
    F_{n,l_n^*} - F_{n,l} & \text{otherwise}
    \end{cases}
\end{equation}
ここで $l_n^* = \arg\max_{l \in \mathcal{L}_n} F_{n,l}$ は宛先 $n$ 内の最良リンクであり、$l_n^{(2)} = \arg\max_{l \in \mathcal{L}_n \setminus \{l_n^*\}} F_{n,l}$ は2番目に高い忠実度を持つリンクである。
\end{definition}

\begin{remark}[Relation between Fidelity and Depolarizing Parameter]
忠実度 $F$ と脱分極パラメータ $p$ は $F = (p+1)/2$ の線形関係にある。したがって、忠実度空間でのギャップ $\Delta F$ とパラメータ空間でのギャップ $\Delta p$ は $\Delta F = \Delta p / 2$ の関係を持つ。本解析における定数項は、この係数を吸収したものとして扱う。
\end{remark}

\begin{definition}[Outer Gap]
宛先 $n$ の外層ギャップ $\Delta_{n}^{\mathrm{out}}$ を以下で定義する。
\begin{equation}
    \Delta_{n}^{\mathrm{out}} := \begin{cases}
    V_n - V_{(K+1)} & \text{if } n \in \mathcal{S}^* \text{ (Optimal set)} \\
    V_{(K)} - V_n & \text{if } n \notin \mathcal{S}^* \text{ (Sub-optimal set)}
    \end{cases}
\end{equation}
ここで $V_{(k)}$ は全宛先の中で $k$ 番目に大きいスコアを表す。
\end{definition}

\begin{definition}[Effective Gap]
リンク $l \in \mathcal{L}_n$ の有効ギャップ $\Delta_{n,l}^{\mathrm{eff}}$ を次式で定義する。
\begin{equation}
    \Delta_{n,l}^{\mathrm{eff}} := \max\left( \Delta_{n,l}^{\mathrm{in}}, \frac{\Delta_{n}^{\mathrm{out}}}{I_{\max}} \right)
\end{equation}
ここで $I_{\max} = \max_{n} I_n \le 1$ である。
\end{definition}

\subsection{Main Theorem}

\begin{theorem}[Sample Complexity]
\label{thm:complexity}
MD-LINKSELFIEは、有限フェーズで停止し、確率 $1-\delta$ 以上で正しい解を出力する。その際にかかる総バウンス数の期待値は以下で上界評価される。
\begin{equation}
    \mathbb{E}[N_{\mathrm{total}}] \le O\left( \sum_{n=1}^{N} \sum_{l \in \mathcal{L}_n} \frac{1}{(\Delta_{n,l}^{\mathrm{eff}})^2} \log \left( \frac{L_{\mathrm{tot}}}{\delta \cdot \Delta_{n,l}^{\mathrm{eff}}} \right) \right) \cdot \overline{m}
\end{equation}
ここで、$L_{\mathrm{tot}} = \sum_{n=1}^{N} |\mathcal{L}_n|$ は全リンク数、$\overline{m} = \sum_{m \in \mathcal{M}} m$ は1回のNBサブルーチンあたりの総バウンス数である。
\end{theorem}


\section{Appendix: Proof of Theorem \ref{thm:complexity}}

\subsection{Step 1: Good Event and Probability}
補題1（LinkSelFiEの信頼区間）に基づき、事象 $\mathcal{E}$ を定義する。
\begin{equation}
    \mathcal{E} = \left\{ \forall s \ge 1, \forall n, l : | \hat{p}_{n,l}^{(s)} - p_{n,l} | \le \varepsilon_s \right\}
\end{equation}
ここで信頼半径 $\varepsilon_s$ は $\delta_s = \frac{\delta}{(s+1)(s+2) N L_{\max}}$ に対応して設定される。Union Boundにより、失敗確率は以下のように抑えられる。
\begin{align}
    \mathbb{P}(\bar{\mathcal{E}}) &\le \sum_{s=1}^{\infty} \sum_{n=1}^{N} \sum_{l \in \mathcal{L}_n} \frac{\delta}{(s+1)(s+2) N L_{\max}} \\
    &\le \sum_{s=1}^{\infty} \frac{N L_{\max} \cdot \delta}{(s+1)(s+2) N L_{\max}} \\
    &= \delta \sum_{s=1}^{\infty} \left( \frac{1}{s+1} - \frac{1}{s+2} \right) = \delta \cdot \frac{1}{2} < \delta
\end{align}
よって $\mathbb{P}(\mathcal{E}) \ge 1-\delta$ である。これ以降、事象 $\mathcal{E}$ が成立している前提で議論する。

\begin{remark}[Decay of Confidence Radius]
$T_s$ の設定式を $\varepsilon_s$ の定義式に代入すると、
\begin{equation}
    \varepsilon_s = \sqrt{\frac{C_{\mathrm{NB}}}{T_s} \cdot \log\left( \frac{(s+1)(s+2) N L_{\max}}{\delta} \right)} = \sqrt{\frac{1}{2^{2s}}} = 2^{-s}
\end{equation}
となり、フェーズ $s$ が進むごとに信頼半径が半減する。これにより、フェーズ $s$ でギャップが $O(2^{-s})$ 程度のリンク・宛先が除去可能となる。
\end{remark}

\subsection{Step 2: Safety of Elimination}

\paragraph{Safety of Inner Elimination:}
真の最良リンク $l^* = l_n^*$ が除去されないことを示す。除去条件は $\hat{p}_{l^*}^{(s)} + \varepsilon_s < \hat{p}_{\max,n}^{(s)} - \varepsilon_s$ である。
Good Event $\mathcal{E}$ 下で、$\hat{p}_{l^*}^{(s)} \ge p_{l^*} - \varepsilon_s$ および $\hat{p}_{\max,n}^{(s)} \le p_{l^*} + \varepsilon_s$ が成立するため、
\begin{align}
    \hat{p}_{l^*}^{(s)} + \varepsilon_s &\ge (p_{l^*} - \varepsilon_s) + \varepsilon_s = p_{l^*} \\
    \hat{p}_{\max,n}^{(s)} - \varepsilon_s &\le (p_{l^*} + \varepsilon_s) - \varepsilon_s = p_{l^*}
\end{align}
したがって $\hat{p}_{l^*}^{(s)} + \varepsilon_s \ge p_{l^*} \ge \hat{p}_{\max,n}^{(s)} - \varepsilon_s$ となり、除去条件は満たされない。

\paragraph{Safety of Outer Elimination (Guaranteed $|\mathcal{A}| \ge K$):}
外層除去において、少なくとも $K$ 個の宛先は除去されないことを示す。
$\Theta_K$ は現在のアクティブ集合 $\mathcal{A}$ における $K$ 番目に大きい LCB である。
LCB が上位 $K$ 位以内にある宛先集合を $\mathcal{K}_{\mathrm{top}} \subset \mathcal{A}$ とすると、定義により $\forall n \in \mathcal{K}_{\mathrm{top}}, \mathrm{LCB}_{n} \ge \Theta_K$ である。
任意の宛先 $n$ について $\mathrm{UCB}_n \ge \mathrm{LCB}_n$ が常に成立するため、
\begin{equation}
    \forall n \in \mathcal{K}_{\mathrm{top}}, \quad \mathrm{UCB}_{n} \ge \mathrm{LCB}_{n} \ge \Theta_K
\end{equation}
となり、これら $K$ 個の宛先は除去条件 $\mathrm{UCB}_n < \Theta_K$ を満たさない。よって常に $|\mathcal{A}| \ge K$ が維持される。

\paragraph{Safety of Outer Elimination for True Top-K:}
真の Top-K 宛先 $n^* \in \mathcal{S}^*$ が除去されないことを示す。Good Event $\mathcal{E}$ 下で、
\begin{align}
    \mathrm{UCB}_{n^*} &= I_{n^*} \left( \hat{F}_{n^*} + \frac{\varepsilon_s}{2} \right) \ge I_{n^*} \left( F_{n^*} - \frac{\varepsilon_s}{2} + \frac{\varepsilon_s}{2} \right) = I_{n^*} F_{n^*} = V_{n^*}
\end{align}
また、閾値 $\Theta_K = \mathrm{LCB}_{(K)}$ について、$\mathrm{LCB}_{(K)} \le V_{(K)}$ が成立する（$K$番目に大きいLCBは、対応する真のスコア以下）。
$n^* \in \mathcal{S}^*$ より $V_{n^*} \ge V_{(K)}$ であるから、
\begin{equation}
    \mathrm{UCB}_{n^*} \ge V_{n^*} \ge V_{(K)} \ge \mathrm{LCB}_{(K)} = \Theta_K
\end{equation}
したがって、$n^*$ は除去条件を満たさない。

\paragraph{Correctness at Stopping Time:}
以上の議論より、真のTop-K宛先および真の最良リンクは決して除去されず、かつ $|\mathcal{A}| \ge K$ が維持される。
したがって、停止条件 $|\mathcal{A}| = K$ かつ $\forall n, |\mathcal{S}_n|=1$ が満たされた時点で、出力解は真の最適解 $(\mathcal{S}^*, \mathcal{L}^*)$ と一致する。

\subsection{Step 3: Sample Complexity and Termination}

\begin{lemma}[Termination]
MD-LINKSELFIE は有限フェーズで停止する。
\end{lemma}
\begin{proof}
Good Event $\mathcal{E}$ 下で、各リンク・宛先の有効ギャップ $\Delta_{n,l}^{\mathrm{eff}} > 0$ が存在する。
$\varepsilon_s = 2^{-s}$ であるから、十分大きなフェーズ $s^*$ において $\varepsilon_{s^*} \le \frac{1}{4} \min_{n,l} \Delta_{n,l}^{\mathrm{eff}}$ が成立する。この時点で全ての劣等リンクおよび劣等宛先は除去され、停止条件が満たされる。
\end{proof}

次に、リンク $l \in \mathcal{L}_n$ の探索が終了するための十分条件を示す。

\paragraph{Case 1: Termination by Inner Elimination}
$\Delta_{n,l}^{\mathrm{in}} \ge 4\varepsilon_s$ のとき、
\begin{align}
    (\hat{p}_{\max} - \varepsilon_s) - (\hat{p}_l + \varepsilon_s) &\ge (p_{l^*} - \varepsilon_s - \varepsilon_s) - (p_l + \varepsilon_s + \varepsilon_s) \\
    &= (p_{l^*} - p_l) - 4\varepsilon_s = \Delta^{\mathrm{in}} - 4\varepsilon_s \ge 0
\end{align}
となり、リンク $l$ は内層除去される。

\paragraph{Case 2: Termination by Outer Elimination}
宛先 $n \notin \mathcal{S}^*$ であり、$\Delta_n^{\mathrm{out}} \ge 4 I_{\max} \varepsilon_s$ のとき、外層除去されることを示す。

まず、$\mathrm{LCB}_{(K)}$ の下界を評価する。真の Top-K 宛先 $n^* \in \mathcal{S}^*$ について、
\begin{equation}
    \mathrm{LCB}_{n^*} = I_{n^*} (\hat{F}_{n^*} - \varepsilon_s/2) \ge I_{n^*} (F_{n^*} - \varepsilon_s) = V_{n^*} - I_{n^*} \varepsilon_s \ge V_{(K)} - I_{\max} \varepsilon_s
\end{equation}
真の Top-K 宛先 $K$ 個は全てアクティブであり、そのLCBは全て $V_{(K)} - I_{\max} \varepsilon_s$ 以上である。
$\mathrm{LCB}_{(K)}$ はアクティブ集合の中で $K$ 番目に大きいLCBであるから、
\begin{equation}
    \mathrm{LCB}_{(K)} \ge V_{(K)} - I_{\max} \varepsilon_s
\end{equation}

次に、$\mathrm{UCB}_n$ の上界を評価する。
\begin{equation}
    \mathrm{UCB}_n = I_n (\hat{F}_n + \varepsilon_s/2) \le I_n (F_n + \varepsilon_s) = V_n + I_n \varepsilon_s
\end{equation}

以上より、
\begin{align}
    \mathrm{LCB}_{(K)} - \mathrm{UCB}_n &\ge (V_{(K)} - I_{\max} \varepsilon_s) - (V_n + I_n \varepsilon_s) \\
    &= (V_{(K)} - V_n) - (I_{\max} + I_n) \varepsilon_s \\
    &= \Delta_n^{\mathrm{out}} - (I_{\max} + I_n) \varepsilon_s \\
    &\ge \Delta_n^{\mathrm{out}} - 2 I_{\max} \varepsilon_s \quad (\because I_n \le I_{\max})
\end{align}

$\Delta_n^{\mathrm{out}} \ge 4 I_{\max} \varepsilon_s$ のとき、
\begin{equation}
    \mathrm{LCB}_{(K)} - \mathrm{UCB}_n \ge 4 I_{\max} \varepsilon_s - 2 I_{\max} \varepsilon_s = 2 I_{\max} \varepsilon_s > 0
\end{equation}
よって $\mathrm{UCB}_n < \mathrm{LCB}_{(K)} \le \Theta_K$ となり、宛先 $n$ は除去される。

蒸留とは、複数の低品質なエンタングルメント対を消費して、高品質なペアを
抽出（純粋化）するプロトコルである。このプロセスにおいて、初期忠実度
が特定のしきい値 Fth​（例: 0.5やそれ以上の特定値）を下回っている場合、
どんなに多くのペアを消費しても忠実度を向上させることは不可能（蒸留不能）
となる。

QKDにおいては、量子ビット誤り率（QBER）が保安限界（例: BB84プロトコル
における約11\%）を超過すると、盗聴者による情報漏洩の可能性を排除できな
くなる。忠実度 F は誤り率と相関するため、これは F がある閾値を下回ると
秘密鍵生成レートがゼロになることを意味する 。



\subsection*{論文での説明のイメージ}
\label{sec:org16c8ae1}
効用関数の定義について 量子通信において、忠実度 F がしきい値 Fth​ をわ
ずかに超えた程度では、蒸留効率（Distillation Yield）は極めて低く、実効
的な通信レートはゼロに近い。 そのため、リンクの効用は単純な F ではなく、
しきい値を超過した「有効マージン (Effective Margin)」に比例すると
みなすのが物理的に妥当である。 よって、本研究では効用関数として
U=I×max(0,F−Fth​) を採用する。これは蒸留可能エンタングルメント量
（Distillable Entanglement）や秘密鍵レートの一次近似に相当する。

\begin{itemize}
\item 初期化と疎なサンプリング:

\item 効用の信頼区間（Utility Confidence Bound）の計算

\end{equation}

\paragraph{最低保証効用（Lower Confidence Bound of Utility）}
\begin{equation}
U_n^{\min}
= I_n \times \max\left(0, (\hat{F}_n - \beta_n) - F_{\mathrm{th}} \right)
\end{equation}

\begin{itemize}
\item グローバルな除去（ノードごとの脱落判定）

もし、あるノード Dk​ の 「最大効用 (Ukmax​)」 が、この Ubestmin​ よりも

判定式: U\_\{\mathrm{best}\}\^{}\{\(\min\)\} = \(\max\)\_\{n \(\in\) \mathcal{D}\}
 U\_n\^{}\{\(\min\)\} ならば Dk​ を除去。
\end{itemize}


\begin{itemize}
\item 予算配分と再計測

生き残ったノードペアに対してのみ、LinkSelFiEのロジックで次フェーズの

\item 重み付き残差二乗和

\subsection*{NBの説明}
\label{sec:orge3f7f42}
ノードA、ノードB間の通信路の品質を推定する時の動き


\begin{enumerate}
\item ノードAで量子ビットを用意する。

\item ノードAで、ランダムなゲート操作を量子ビットに加える。

\item ノードAからノードBへ量子ビットを送信する。

\item 受け取ったノードBでも、ランダムな操作を加える。

\item ノードBからノードAへ量子ビットを送り返す。(この「A→B→A」の往復を「1
回のバウンス」と呼ぶ)

\item このバウンス（手順2〜5）を m 回繰り返す。何度も通信路を通すことで、
わざと通信エラーを蓄積させるため。

\item 最後に、これまでのランダム操作をすべて打ち消して、元の状態に戻すた
めの「逆操作」をノードAで行う。もし通信路や操作が完璧なら、量子ビッ
トは完全に元の状態に戻る。

\item 実際に元の状態に戻っているかを確認（測定）する。(結果は0,1で取得)

\item 上記の手順を、操作の組み合わせをランダムに変えながら何度も行い、成
功率（平均生存率）を出す。
\end{enumerate}

NBプロトコルで得られた出力データ \(\{\bar{b}_m\}_{m \in \mathbb{M}}\) は、
以下の単一指数関数にフィッティングすることができる：
\begin{equation}
\bar{b}_m = A f^m
\end{equation}

データ \(\{\bar{b}_m\}_{m \in \mathbb{M}}\) に対する指数関数フィッティングに通常最小二乗法（Ordinary Least Squares, OLS）が用いられる。OLS はすべてのデータ点を等しい重みで扱い、残差二乗和
\begin{equation}
S_{OLS} = \sum_{m \in \mathbb{M}} (\bar{b}_m - A f^m)^2
\end{equation}
を最小化することでパラメータ \(A\) および \(f\) を推定する。

\subsection*{詳しい説明}
\label{sec:org0059026}
linkselfieでは1回のNBで10バウンス使用する設定。つまり10バウンス単位で
の測定をしている。

手法1(現状) \\
\noindent
link1 4NB(40バウンス) → O \\
link2 4NB(40バウンス) → X \\
link3 4NB(40バウンス) → X \\
link4 4NB(40バウンス) → X

これである程度判別可能。
工夫すると以下のようにできるかもしれない

手法2 \\
\noindent
link1 2NB → +1NB → 1NB → O \\
link2 2NB → +1NB → 1NB → X \\
link3 2NB → +1NB → X \\
link4 2NB →  X

これでもいいが、
4NBを振りわけるだけでは面白くない。
新規性がない。
そこで以下のような方式を考えた

手法3 \\
\noindent
link1 2NB → +0.5NB → +0.5NB → 0.3NB → O \\
link2 2NB → +0.5NB → +0.5NB → 0.3NB → X \\
link3 2NB → +0.5NB → +0.5NB → X \\
link4 2NB → +0.5NB → X

1NBあたりに使用するバウンス数をフェーズごとに変更できるようにするため
に、非均一測定回数配分を許容するネットワークベンチマーキング拡張が必要。
特筆すべき点として、柔軟に資源配分できるだけはなく、1バウンスから得ら
れる情報量を増やすことが可能になることが挙げられる。
手法2 \\
link3 2NB → +1NB → X  合計30バウンス

手法3 \\
link3 2NB → +0.5NB → +0.5NB → X  合計30バウンス

この例だとlink3に対して使われた総バウンスは
手法2と3で同じである。
普通に考えると手法2と3のlink3に対する忠実度の推定精度は同等であるはず。
しかし、提案手法が実現できると1バウンスから得られる情報量を増やすこと
が可能になるため、手法3の推定精度が手法2の推定精度を上回るというような
ことが起こると考えている。

1NBから得られる情報量を増やすことが可能になっている点に新規性がある。NBの回
数だけでなく、情報利得に基づいた適切なバウンス長m∈Mも同時に制御するこ
とで大幅なコスト削減ができる可能性がある



\subsection*{ストーリー案トピックセンテンス}
\label{sec:orgc270374}
\subsubsection*{背景1: 量子ネットワークでは、オンライン学習による忠実度推定が必要である}
\label{sec:org92c0017}
量子ネットワークでは、
ノイズにより品質が未知である多数の量子リンクの中から、
忠実度の高いリンクを高精度で判定する際に
すべて一様に測定を行うことはリソースの浪費となるため、
測定から得られるフィードバックに基づき、逐次的意思決定を行うことで、
効率的に有望なリンクにリソースを集中させる、
オンライン学習に基づくリンク品質推定が必要である。


\subsubsection*{背景2: オンライン推定を行う既存プロトコルは、NBを採用している}
\label{sec:org3c17c7d}
LinkSeLFiEやQBGP等の既存プロトコルは、
SPAMエラーとリンク品質を指数モデルへのフィッティングにより分離推定でき、
トポロジーの知識を必要としない、
Network Benchmarking (NB) をサブルーチンとして採用している。


\subsubsection*{背景3: NBには情報利得（Fisher情報量）が最大となる特定の m が存在する}
\label{sec:org7ffdef5}
NBには、
バウンス長 m に対して2m個のエンタングルメントペアを消費することから、
1エンタングルメントあたりのFisher情報量として定義される情報利得 I(pi, m) = 16Ai²mp\^{}(4m-2)i を最大化する、
最適なバウンス長 mi* = arg max\{m∈M\} I(pi, m) が存在し、
これを選択することで同一コストに対する不確実性の削減量を最大化できる。

\subsubsection*{背景4: NBの均一配分するという制約がリンク選択、経路選択アルゴリズムと統合する際に障壁となっている}
\label{sec:org33a68cb}
NBは全てのバウンス長に対して均一な測定回数を割り当てることを前
提としており、LinkSeLFiEではその制約が推定精度への寄与度が低いバウンス
長にも無駄なリソースを消費する原因となっている。
一方、QBGPでは情報利得（Fisher情報量）が最大となる特定の m に測定を集中させる戦略をとるが、
均一配分の制約により、bmを蓄積し、回帰することができないため、
フィッティング係数 A は初期フェーズの推定値に固定され、
ロバストにAを求めれない可能性がある。

\subsubsection*{動機: 非均一配分を許容するNBの拡張が必要である}
\label{sec:orgf11a488}
これらの問題を解決するために、
情報利得の高いバウンス長に基づき探索効率を最大化でき、
フィッティング係数 Aをロバストに回帰できる、
非均一配分を許容するNBの拡張が必要である
